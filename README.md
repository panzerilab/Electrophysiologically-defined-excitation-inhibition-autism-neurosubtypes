# Electrophysiology Analysis and Figure Generation — Bertelsen et al. (Dec 2025)

This repository contains all the code required for the analysis and generation of figures presented in the paper:

**Bertelsen et al., New Version, December 2025**.

## Folder Overview

- **Ephys-Analysis-main**  
  Code for processing and analysis of electrophysiological data can be found at 
  https://github.com/panzerilab/Ephys-Analyses

- **Simulations_&_aexp_analysis**  
  Contains scripts to run simulations and additional analyses.  
  To use:  
  1. Adjust the paths in the scripts to output electrophysiological analysis results to the `DATA` folder within this directory.  
  2. Run the scripts as needed.  
  Individual subfolders may contain their own `README.md` with specific instructions.

## Purpose

This repository provides a complete workflow from raw electrophysiological data to processed, chunked data, feature extraction, analysis, and figure generation for the paper.  
It is designed to reproduce all analyses and figures reported in **Bertelsen et al. (Dec 2025)**.
